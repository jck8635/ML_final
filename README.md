# 🛡️ 머신러닝 기반 텍스트 유해 표현 탐지 서비스

공백/특수문자 변형(Character) 및 문맥/단어(word) 의미 탐지를 위한 **TF-IDF 벡터화**와 **SVC(Linear SCV)** 알고리즘을 활용하여, 입력된 텍스트의 유해 여부를 사전에 탐지하고 판단 근거(가중치 및 기여 점수)를 시각화해 주는 웹 애플리케이션입니다.
데이터셋을 기반으로 학습을 시킨거라 아직 정상 텍스트들도 오판하는 상황이 일어날 수 있습니다.

## 📌 주요 기능

- **2가지 모델 동시 분석**: 문자 단위(공백/특수문자 변형 탐지)와 문맥/단어 의미 탐지 모델을 함께 구동하여 예측 정확도를 높였습니다.
- **Explainable AI (설명 가능한 AI)**: 단순히 "유해/정상" 결과만 알려주는 것이 아니라, 문장 속 어떤 단어가 유해 판단에 얼마만큼 영향을 주었는지 **유해 방향 가중치**와 **판정 기여 점수**를 표로 transparent하게 보여줍니다.
- **직관적인 Streamlit UI**: 누구나 쉽게 문장을 입력하고 실시간으로 유해 확률(%) 및 결과를 시각적으로 확인할 수 있습니다.
